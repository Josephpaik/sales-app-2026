# ADR 0002: 기기별 화면 분할 전략 — 현장 최대 2단, 사내 3단 이상

## 1. 상태 (Status)
- 현재 상태: 수락됨(Accepted)
- 결정 날짜: 2026-09-18
- 승인자: CISO 백원광

## 2. 배경 (Context)
- 현장 영업은 이동 중 빠른 조회·입력이 목적이고, 사내 영업관리는 대량 데이터 모니터링과 검토가 목적이다. 같은 분할을 쓰면 한쪽이 반드시 비효율적이다.

## 3. 결정 (Decision)
| 구분 | 현장 영업 (모바일/태블릿) | 사내 영업관리 (PC 웹) |
|---|---|---|
| 권장 분할 | 최대 2단 (태블릿), 폰은 1단 전환 | 3단 이상 다단 분할 |
| 구조 | 왼쪽: 고객/영업 건 목록, 오른쪽: 현재 건의 상세·활동 | 1단 네비게이션, 2단 파이프라인/실적·목록, 3단 세부 필터·상세 |
| 핵심 컴포넌트 | Drawer(Popup left), Bottom Sheet(Popup bottom), ActionSheet | Sider, Splitter, Table |
| 목표 | 빠른 정보 입력과 기동성 | 대량 데이터 모니터링·검토 |

- 브레이크포인트: 768 / 1200px. 시연 강제 옵션 `?device=`.
- 모바일 등록 폼은 필수 항목만 받고 나머지는 PC에서 보완한다(입력 부담 최소화).

## 4. 결과 (Consequences)
- 긍정적 효과: 각 환경에 맞는 정보 밀도. 라우트가 같아 링크 공유·뒤로가기가 기기와 무관하게 동작.
- 부정적 영향/비용: 페이지마다 두 렌더링을 유지해야 함 → 화면 정의서에 PC/모바일 항목 차이를 명시해야 하며, 모바일에서 제외한 기능(제품 라인 편집, 계약 등록 등)의 목록을 UAT 시나리오에 반영해야 한다.
