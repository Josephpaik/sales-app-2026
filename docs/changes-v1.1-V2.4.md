## 7. 검증

- `npm run build` (tsc + vite) 통과, Playwright로 1600/1024/390px 전 라우트 스크린샷, 콘솔·페이지 오류 0건.
- E2E 흐름: 증설 등록(본사업 필수 확인) → 서티 승인대기 → 제품라인 추가(제품분류 연동·HyBoost 수량) → 서티 미승인 수주 전이 차단 → 승인 후 수주 → 발급 신청·출고 요청 → 전체화면 납품·검수·발급 탭에서 완료 처리 → 라이선스 발급이력 반영 → 매출채권 등재·입금 등록 → 가마감 실적보고 확정 저장.

## 8. 수행계획서(1차 범위)와의 관계

V2.4로 추가된 매출채권·라이선스 발급·HyBoost 출고·내부보고·집계통계는 수행계획서 v1.1 §2-2 기준으로 "검토/후속"에 해당한다. 본 프로토타입은 화면 흐름 검증용이며, 1차 개발 포함 여부는 분석 단계 종료 시 범위 판정(절단 규칙: 대시보드 → 관리자 일부 → 계약 상세 → 검토 항목)에서 확정한다. `/roadmap` 화면의 범위표에 해당 행을 추가했다.
