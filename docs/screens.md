## 상태 전이 (5단계 11종)

- 포케스팅(대기) → 영업중 / 실주
- 영업중 → 분기예측 / 수주 / 실주 / 이전영업
- 분기예측 → 수주 / 실주 / 이전영업
- 수주 → 구축대기 / 검수중 (서티 승인완료 필수)
- 구축대기 → 검수중 → 검수완료(검수완료 처리 선행) → 완료(미수) / 완료(수금)
- 완료(미수) → 완료(수금) (전액 입금 시 자동)
- 완료(수금)·이전영업·실주: 종결

수주 전이 시 원가명세서·매출견적서가 없으면 차단하지 않고 경고를 기록한다(1차 v2.3 권고안 유지).
