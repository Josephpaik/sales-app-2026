## 상태 전이 (SN 코드 15종)

`src/types/index.ts` `SALES_STATUS[].next`

- 영업메모 → 포케스팅(대기) / 취소
- 포케스팅(대기) → 영업중 / 취소
- 영업중 → 분기예측 / 수주 / 실주 / 이전영업
- 분기예측 → 수주 / 실주 / 이전영업
- 수주 → 당월세금계산서 / 구축대기
- 당월세금계산서 → 구축대기 / Billing
- 구축대기 → 구축중 → 검수중 → 검수완료 → Billing → 완료
- 완료·이전영업·실주·취소: 종결(전이 없음)

수주 전이 시 원가명세서·견적서 첨부가 없으면 **차단하지 않고 경고를 기록**한다(1차: 미결 6-1·6-2 확정 전 v2.3 권고안).
